# Competențe digitale – site de curs (Teorie + Practică)

- `index.html` – Teorie (recap pe zile, broșuri, slide-uri, teste cu răspunsuri)
- `practica.html` – Practică (calendar pe subgrupă, fișe cu pași, hartă a celor 21 de teme)
- `stil.css`, `ui.js` – aspectul și funcțiile comune (sticlă mată, tooltip-uri, glosar)
- `linkuri.js` – AICI se lipesc linkurile NotebookLM pentru fiecare zi de teorie
- `fonturi/` – Lora și Karla, găzduite local (fără cereri către terți)
- `brosuri/`, `slide-uri/`, `montaje/`, `fise/` – materialele descărcabile
- `404.html` – pagina afișată pentru adrese inexistente

Site fără cookie-uri și fără colectare de date. Pagini marcate noindex.
